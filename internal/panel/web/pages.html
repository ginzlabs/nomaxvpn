NoMax privacy

NoMax is private: only people the admin invites can use it. It is not a commercial service.

What the server stores

  • The name the admin gave you, and a short-lived PIN while an invite is open.
  • For each device: its name, a WireGuard public key, random credentials, when it last connected and how many bytes it moved in total.

What it does not store

  • No websites, domains, DNS queries or connection logs.
  • No email, phone number, location, contacts or analytics.

In the NoMax app, your device's private key is created on the device and never leaves it. When you join from the web page, the server creates the key, shows it to you once and does not keep it. Removing a device or a person deletes their records immediately.

To show which address websites see, the app asks Cloudflare's public trace page at 1.1.1.1 when it connects or disconnects, or when you tap the address. Cloudflare sees what any website would. On Android, while connected, the NoMax server asks on the app's behalf, since all your traffic leaves from there anyway.
